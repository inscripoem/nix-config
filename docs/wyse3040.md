# Wyse 3040

The Wyse 3040 is an Atom x5-Z8350 thin client that ran NixOS before being
migrated to DietPi. NixOS management was removed from this flake on
2026-10-29. This page records the hardware quirks that outlive the old
configuration and the current DietPi layout.

## 1. Hardware quirks

- **UEFI fallback boot path:** the firmware ignores NVRAM boot entries and
  only honours `\EFI\BOOT\BOOTX64.EFI`. A bootloader must be installed to
  that removable-media fallback path (GRUB did this with
  `efiInstallAsRemovable = true` and no NVRAM writes).
- **`dw_dmac` blacklist:** the `dw_dmac_core` module hangs shutdown and
  reboot on this hardware. The module must stay blacklisted, or every
  restart hangs.
- **`reboot=efi` kernel parameter:** forced UEFI runtime reboot; required
  together with the blacklist for reliable restarts.
- **MMC device numbering drift:** the built-in eMMC and the SD card
  enumerate in unstable order (`/dev/mmcblk0` and `/dev/mmcblk1` swapped
  between kernels). Anything addressing these disks must use
  `/dev/disk/by-id/` symlinks, never `mmcblkN`.
- **Wireless card is 2.4 GHz-only.**
- **Wired NIC:** Realtek rtl8168h; its non-free firmware must be available
  for the link to come up.

## 2. Current DietPi layout

- The eMMC carries the root partition (7 GB). The ESP was moved to the end
  of the disk and resized online.
- The SD card is the data disk, mounted at `/mnt/data`; Docker's data root
  lives there.
- Network: the wired Ethernet address ends in `.161`, the wireless one in
  `.180`.
- Tailscale address `100.70.189.21` is the out-of-band rescue channel when
  the LAN addresses are unreachable.
- Three hardware safeguards were carried over from the NixOS era: the
  `dw_dmac` blacklist, the `reboot=efi` kernel parameter, and a persisted
  WiFi power-save disable.

## 3. Removal from the flake

The host entry, per-host modules, Home Manager entry, builder key, and
SOPS recipient were removed on 2026-10-29; the host no longer appears in
[outputs/default.nix](../outputs/default.nix). The old NixOS
configuration is backed up on `briefcase` at `~/wyse3040-backup/`.

The [impermanence](../modules/nixos/capabilities/impermanence.nix),
[sdcard](../modules/nixos/capabilities/sdcard.nix), and
[remote-build-client](../modules/nixos/capabilities/remote-build-client.nix)
capabilities remain in the flake as fleet-generic capabilities; they
currently have no consumer.
